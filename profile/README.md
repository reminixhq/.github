[![Reminix](banner.png)](https://reminix.com)

Reminix turns your scripts into internal tools. Upload a Python, shell or Node script, and Reminix runs it from a form, the API, the CLI or your AI agents, on a schedule or from a webhook. Keys stay out of the code, and every run is on record.

## Start

```bash
npm install @reminix/sdk                 # TypeScript
pip install reminix                      # Python
npm install -g @reminix/cli              # the command line
npx skills add reminixhq/reminix-skills  # your AI agent
```

Then follow [the quickstart](https://reminix.com/docs/quickstart/).
